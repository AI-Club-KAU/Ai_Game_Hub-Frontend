# Dev Run | سباق أسبوع التطوير

## 1. نبذة عن اللعبة

**Dev Run** لعبة ركض (Runner) بطابع تقني، من تطوير نادي الذكاء الاصطناعي بجامعة الملك عبدالعزيز ضمن أسبوع التطوير (Dev Week). يتحكم اللاعب بروبوت يركض على طريق رقمي، ويخوض رحلة بناء نموذج ذكاء اصطناعي عبر ثلاث مراحل: جمع البيانات، وتدريب النموذج، ثم نشره.

خلال اللعب، يتجنب اللاعب العقبات، ويجمع العناصر المطلوبة لكل مرحلة، ويجيب عن أسئلة قصيرة حول مفاهيم الذكاء الاصطناعي. تجمع اللعبة بين التحدي وسرعة الاستجابة والتعلّم التفاعلي.

## 2. فكرة اللعبة ومراحلها

تتكون اللعبة من ثلاث مراحل متتابعة:

1. **جمع البيانات (Data Collection):** يجمع اللاعب حزم البيانات (Data Packets) التي تمثل البيانات اللازمة لتجهيز النموذج.
2. **تدريب النموذج (Model Training):** يجمع اللاعب أنوية التدريب (Training Cores) التي تمثل التقدم في تدريب النموذج.
3. **نشر النموذج (Model Deployment):** يجمع اللاعب مفاتيح النشر (Deployment Keys) التي تمثل استكمال عملية نشر النموذج.

مدة الركض في كل مرحلة 40 ثانية. تزداد سرعة الروبوت تدريجياً مع الانتقال بين المراحل، كما تزداد بعد الإجابة عن كل سؤال.

## 3. طريقة اللعب والتحكم

هدف اللاعب هو الاستمرار في الركض، وتفادي العقبات، وجمع العناصر، والإجابة عن الأسئلة.

| الحركة | الكمبيوتر | الجوال (اللمس) |
|---|---|---|
| المسار الأيمن | السهم → أو D | السحب يميناً |
| المسار الأيسر | السهم ← أو A | السحب يساراً |
| القفز | السهم ↑ أو W أو Space | السحب للأعلى |
| الانزلاق | السهم ↓ أو S | السحب للأسفل |
| الإيقاف المؤقت | زر ⏸ أو Esc | زر ⏸ |

تحتوي واجهة اللعب على زر للإيقاف المؤقت، وزر لملء الشاشة. ومن نافذة الإيقاف يمكن استئناف اللعب أو الرجوع للصفحة الرئيسية. وبعد انتهاء الجولة يمكن إعادة اللعب أو الرجوع للصفحة الرئيسية.

## 4. العقبات والعناصر القابلة للجمع

تظهر في الطريق أنواع مختلفة من العقبات التي يجب على اللاعب تفاديها:

- **الأخطاء البرمجية (Bugs)**
- **الفيروسات (Viruses)**
- **البيانات التالفة (Corrupted Data)**
- **حواجز النظام والليزر (System Errors / Laser Barriers):** تتطلب اختيار الحركة المناسبة، القفز أو الانزلاق، بحسب نوع الحاجز.

والعناصر القابلة للجمع مرتبطة بالمراحل الثلاث:

- حزم البيانات (Data Packets)
- أنوية التدريب (Training Cores)
- مفاتيح النشر (Deployment Keys)

يوجد 10 عناصر لكل مرحلة، أي 30 عنصراً في الجولة كاملة.

## 5. نظام تقدم الذكاء الاصطناعي (AI Progress System)

تعرض اللعبة ثلاثة مؤشرات تقدم منفصلة:

- **جمع البيانات:** تقدم جمع البيانات.
- **التدريب:** تقدم تدريب النموذج.
- **الإطلاق:** تقدم نشر النموذج.

يتقدم كل مؤشر عند جمع العناصر المخصصة لمرحلته، ويحتاج اللاعب لجمع العناصر العشرة الخاصة بكل مرحلة للوصول بمؤشرها إلى 100%.

تظهر رسالة نجاح نشر النموذج عند اكتمال المؤشرات الثلاثة والوصول إلى نهاية الجولة.

## 6. الأسئلة وآلية احتساب النقاط

تظهر الأسئلة خلال الجولة لاختبار معرفة اللاعب بمفاهيم الذكاء الاصطناعي، وتتوقف اللعبة حتى يجيب اللاعب. وعددها 10 أسئلة باللغة الإنجليزية، موزعة كالتالي:

- جمع البيانات: 4 أسئلة
- تدريب النموذج: 4 أسئلة
- نشر النموذج: سؤالان

تتنوع الأسئلة بين الاختيار من متعدد والصح والخطأ، وتُخلط مواضع الخيارات في أسئلة الاختيار من متعدد.

| مصدر النقاط | طريقة الاحتساب | الحد الأقصى |
|---|---|---|
| الأسئلة | 5 نقاط لكل إجابة صحيحة × 10 أسئلة | 50 |
| العناصر القابلة للجمع | نقطة لكل عنصر × 30 عنصراً | 30 |
| مكافأة عدم الاصطدام | عند إنهاء الجولة بدون أي اصطدام | 10 |
| مكافأة إكمال الجولة | عند الوصول إلى خط النهاية | 10 |
| **المجموع** | | **100** |

التختيم الكامل يمنح **100 نقطة**، والنتيجة لا تتجاوز 100.

## 7. مدة اللعبة والمحاولات والسرعة

- **مدة اللعبة: من دقيقتين إلى 3 دقائق**، دقيقتان من الركض (40 ثانية لكل مرحلة)، بالإضافة إلى وقت الإجابة على الأسئلة.
- لدى الروبوت **3 بطاريات**، ويخسر بطارية عند كل اصطدام. وتنتهي الجولة عند نفادها.
- تزداد السرعة تدريجياً بين المراحل، وبعد الإجابة عن كل سؤال، مع وجود حد أعلى للسرعة.
- يمكن إيقاف اللعبة مؤقتاً ثم استئنافها.

## 8. طريقة تشغيل اللعبة

1. فك ضغط ملف `Dev-Run.zip`.
2. افتح مجلد `Dev-Run`.
3. افتح ملف `index.html` باستخدام متصفح حديث، مثل Google Chrome أو Microsoft Edge أو Safari.
4. اضغط زر **ابدأ اللعب**.

لا تحتاج اللعبة إلى اتصال بالإنترنت أو أي تثبيت.

## 9. ملفات المشروع

```
Dev-Run/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── fonts/
```

- `index.html`: هيكل صفحات اللعبة وعناصر الواجهة.
- `style.css`: التصميم والألوان والتجاوب مع أحجام الشاشات.
- `script.js`: منطق اللعبة، والتحكم، والمراحل، والعقبات، والعناصر، ونظام التقدم، والأسئلة، واحتساب النقاط.
- `assets/fonts/`: ملفات خط Tajawal المحلية.

## 10. ملاحظات تقنية

- مطورة باستخدام **HTML و CSS و JavaScript** فقط، بدون مكتبات أو روابط خارجية.
- تُستخدم لوحة الرسم (Canvas) لعرض مشهد اللعب، وعناصر HTML لعرض الواجهة ومؤشرات التقدم والأسئلة والأزرار.
- الخط محلي داخل مجلد الموارد، والأصوات يولّدها الكود.
- متجاوبة مع الجوال واللابتوب، وتدعم اللمس والماوس ولوحة المفاتيح العربية والإنجليزية.
- زر ملء الشاشة يُخفى تلقائياً في iPhone لأن متصفح Safari لا يدعمه.

### استلام النتيجة النهائية

عند انتهاء الجولة (فوز أو خسارة)، تُتاح النتيجة النهائية (رقم من 0 إلى 100) بطريقتين:

**1. متغير عام:**

```js
window.finalScore
```

**2. رسالة للصفحة الأم** (عند عرض اللعبة داخل iframe):

```js
window.addEventListener('message', (e) => {
  if (e.data && e.data.type === 'DEV_RUN_FINAL_SCORE') {
    console.log(e.data.score); // النتيجة النهائية
  }
});
```
