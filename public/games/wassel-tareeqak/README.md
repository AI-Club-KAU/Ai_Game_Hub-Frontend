# وصّل طريقك — ملاحظات للدمج في النظام

## النقاط للنظام
بعد كل جولة ترسل اللعبة للصفحة اللي فاتحتها (`postMessage`):
```js
{ type: "wassel-tareeqak:result", playerId, score, reached, time, correct, wrong }
```
- `score` من 100.
- اختياري: `?pid=...` و`?name=...` في رابط اللعبة يرجعون مع النتيجة ويعبّون الاسم.

## ⚠️ لا تعدّلون هذي
اللعبة ترسل نتائجها **بعد** لشيت قوقل خاص بقسمنا (لوحة الأبطال حقت اللعبة). هذا منفصل عن النظام ولا يأثر على لوحة النظام.

- **`config.js`:** فيه رابط الشيت. **لا تحذفونه ولا تعدّلونه.**
- **إعدادات الأمان (CSP):** لو فيه تقييد للاتصالات، اسمحوا بـ `https://script.google.com` و`https://script.googleusercontent.com` في `connect-src`.
- **iframe sandbox:** لو تستخدمونه، لازم يكون فيه `allow-scripts allow-same-origin`.

أي سؤال: تواصلوا مع قسم اللعبة قبل أي تعديل.
